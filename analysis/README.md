# Analysis

Place exploratory notebooks and findings here.

Suggested first checks:
- Inspect image dimensions, brightness, and image quality.
- Display images with their annotation masks.
- Identify repeated image filenames across annotator records.
- Design validation splits that keep the same source image together.
- Review missed filaments, fragmented masks, and merged predictions.

Save generated plots and large analysis outputs under `outputs/` at the repository root.
